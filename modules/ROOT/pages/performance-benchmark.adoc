= Performance Benchmarks

MuleSoft Intelligent Document Processing (IDP) performance benchmarks provide throughput measurements, latency distribution data, scalability behavior analysis, and performance optimization guidance under baseline, stress, and peak load conditions.

These benchmarks provide essential data for understanding expected performance envelopes, IDP behavior under different workloads, and designing implementations that remain stable and performant at scale. The metrics support workload sizing, concurrency configuration, and scaling event planning.

The benchmark metrics serve as reference points for designing stable and scalable IDP implementations rather than hard limits. These results support:

* Capacity planning: P95 latency and throughput values provide baselines for SLA planning
* Workload design: Steady-state volumes in "moderate" ranges deliver predictable performance; peak loads are supported but may introduce queuing delays
* Proactive monitoring: Tracking queue depth, error rates, and latency distributions helps identify scaling and load distribution requirements
* Expectation setting: Performance varies based on document size, complexity, and environment. These benchmarks illustrate expected ranges under controlled test conditions

The benchmark data serves as a planning and best-practices reference for anticipating performance, aligning SLAs, and tuning deployments for stability and resilience.
