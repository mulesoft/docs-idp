== Select the Response from Einstein

To configure Einstein to analyze and extract data for a given prompt: 

. In the document action builder, xref:creating-document-actions.adoc#add-prompts[add a new prompt] to a document action or edit an existing one.
. Run a document analysis to generate results in the *Outputs* panel. 
. Click the dropdown button (image:prompt-dropdown.png[4%, 4%, "The prompt dropdown icon."]), next to a prompt's result.
. Select the response labeled *Einstein*.
